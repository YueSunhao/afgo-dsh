# afgo-dsh v1.6.1 安装与升级指南

发布日期：2026-11-24。

正式发布页：https://github.com/YueSunhao/afgo-dsh/releases/tag/v1.6.1

## 这一版更新了什么

- 独立侧栏工作台：从左侧「星使智算」直接进入任务、工具目录和设置。
- 工作台全屏与响应式布局：支持进入、退出全屏，以及宽屏双栏／窄屏单栏切换。
- 首次 API Key 配置：未配置时展示连接表单；连接失败显示原因并可重试；失效 Key 可重新验证。
- 工具图标：优先平台公开原图，缺图时显示有来源标记的替代图标，断网时使用本地图形。
- 修复高度测量及 CI 测试依赖；插件包、工作台和 Python 客户端统一版本号为 1.6.1。

相较此前公开下载的 v1.2.0，本安装包还包含工作台任务恢复与时间线、离线 Mol* 结构查看器、结果图片导出及 DSH 对话中的持久图片汇报；历史版本细节见仓库的 `CHANGELOG.md`。

## 运行条件

- DeepSeek Harness 桌面端；本轮本机测试环境为 0.2.2-rc.2。
- Python 3.8 或更高版本；插件宿主 Node 要求以包内 `engines` 为准。
- 有效的 AsterFire Go API Key。结构图导出需要本机兼容的 Chromium 浏览器。

## 新安装

### 方法一：GitHub 固定版本

在 DSH 插件管理器中添加：

```text
github:YueSunhao/afgo-dsh#v1.6.1
```

也可以在终端执行：

```bash
dsh plugin --profile desktop add 'github:YueSunhao/afgo-dsh#v1.6.1'
```

### 方法二：下载插件安装包

1. 在发布页下载 `afgo-dsh-1.6.1.tgz`、`INSTALL-v1.6.1.md` 和 `SHA256SUMS.txt`。
2. macOS／Linux 可在下载目录执行 `shasum -a 256 -c SHA256SUMS.txt`，核对安装包和指南的 SHA-256。
3. 在终端安装，路径替换为本机实际位置：

```bash
dsh plugin --profile desktop add /absolute/path/afgo-dsh-1.6.1.tgz
```

4. 重新加载或重启 DSH，点击左侧「星使智算」。
5. 在首次连接卡片粘贴自己的 API Key，点击「验证并保存」。

## 已有用户升级

执行与 GitHub 固定版本安装相同的命令，替换已有插件依赖：

```bash
dsh plugin --profile desktop add 'github:YueSunhao/afgo-dsh#v1.6.1'
```

如使用下载包安装，重新执行对应 `.tgz` 的安装命令即可。升级后重启 DSH，宿主保存的账号 Key 可继续验证使用。

固定到 `#v1.6.1` 后，以后升级需将来源中的版本号改为目标版本。希望跟随主分支的用户可以使用 `github:YueSunhao/afgo-dsh`，之后用以下命令更新：

```bash
dsh plugin --profile desktop update afgo-dsh --latest
```

## 升级后核对

- 左侧导航出现「星使智算」，点击后打开独立工作台。
- 「设置 → 关于」显示 `afgo-dsh v1.6.1`；包内客户端执行 `python3 scripts/afg.py --version` 返回 `afg 1.6.1`。
- 未配置账号时显示 API Key 表单，已配置时可验证已有账号。
- 可打开已有任务、切换目录、进入并退出全屏；无需新增计算即可核对界面。

## 验证记录

发布前通过本机 DSH 运行时的 53 项 JavaScript 测试、9 项 Python 测试，以及真实 Chromium 的全屏、首次连接、图标和响应式交互检查。首次连接使用离线测试数据，未改动用户生产 Key。桌面窗口未做人工点验；完整范围见 `docs/PR5-REVIEW.md`。

## 安装包内容

`.tgz` 是 DSH 可安装的 npm 插件包，包含插件清单、宿主与客户端代码、离线 Mol* 查看器、Python 客户端、许可声明、示例及文档。首次安装由包管理器安装运行依赖；这不是包含所有依赖的离线安装器。

## 已知界面限制

中英文词典目前覆盖工具栏、页签与连接外壳，部分正文仍为中文。工具图标的远程图片不可用时会自动降级为本地图形。
